## مميزات الموقع
- **بدون أي إطار عمل (Zero Framework):** مبني بـ HTML5 + CSS3 الحديث + Vanilla JavaScript، سريع جداً ومتوافق 100% مع استضافة **GitHub Pages** المجانية.
- **دليل تفاعلي كامل للمترشحين (33 مترشحاً):**
  - قائمة المجلس الشعبي البلدي لبلدية القنطرة (22 مترشحاً بالصور الفردية، الترتيب، السن، المؤهل العلمي، والمهنة).
  - قائمة المجلس الشعبي الولائي القنطرة (11 مترشحاً بالصور الفردية والسير الذاتية).
  - بحث فوري بالاسم أو الرقم أو التخصص + بطاقة رقمية قابلة للمشاركة لكل مترشح.
- **تسليط ضوء خاص (Spotlight):** قسم مخصص للمترشح **بن حفيظ أحمد تقي الدين (رقم 08 - المجلس الشعبي البلدي)**.
- **البرنامج الانتخابي الرباعي لبلدية وولاية القنطرة:** بيئة نظيفة وإطار عيش أفضل، استثمار وفرص عمل، بنية تحتية متطورة، وتنمية محلية تشاركية.
- **معرض الملصقات الرسمية:** إمكانية تكبير وتحميل جميع الملصقات الرسمية بجودة عالية.

## ربط الدومين `elkantra.com` مع GitHub Pages
تم تضمين ملف `CNAME` داخل المستودع بقيمة `elkantra.com`. لتفعيل الدومين:
1. في مستودع GitHub (`okba14/elkantara`)، اذهب إلى **Settings** > **Pages**.
2. تحت **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
3. في لوحة تحكم الدومين `elkantra.com` (DNS Settings)، أضف سجلات `A` التالية لـ `@`:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. وأضف سجل `CNAME` للاسم `www` يشير إلى `okba14.github.io`.
5. فعّل خيار **Enforce HTTPS** في صفحة إعدادات GitHub Pages بعد التحقق من الدومين.
